# C Programming: Matrix Algorithms for Business Applications

Laboratory coursework developed for Computer Programming at ASE Bucharest.

## Overview
This repository contains C implementations solving practical business problems through two-dimensional arrays and matrix operations. 

The exercises focus on sales tracking across days and products, alongside client telecom billing analysis across monthly intervals.

## Implemented Problems
* Daily Sales Target Verification: Computes daily total sales across all products and reports days falling below an established revenue threshold.
* Minimum Daily Sales Finder: Scans product sales per day to isolate the minimum transaction value.
* Total Daily Sales Aggregator: Traverses matrix columns to compute and report aggregate daily revenue.
* Sales Range and Amplitude: Evaluates volatility per product by determining minimum, maximum, and amplitude metrics across observed days.
* Monthly Billing Thresholds: Calculates monthly customer expenses and flags billing cycles below budget limits.
* Client Average Monthly Usage: Computes the arithmetic mean of call charges per subscriber across multiple billing months.
* Target Call Value Search: Locates and indexes specific months where client consumption matches target values.
* Below-Threshold Month Counter: Tallies the total number of billing cycles falling below defined credit limits for each subscriber.
